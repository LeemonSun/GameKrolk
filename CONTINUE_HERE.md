# Точка продолжения — подготовка 0.0.4

Пользователь спросил, можно ли выключить ПК. Все изменения сохранены локально. Не обещать работу при выключенном компьютере. Не удалять пользовательские сохранения и не закрывать его игру принудительно.

## Что сделано в текущем проходе

- Формат сохранения 4 с миграциями 1/2/3. scripts/combat_snapshot.gd сохраняет RNG через строки int64, текущие удары, цели/маршруты, стрелы, яд, усиления, следы и эффекты. World сохраняет свои таймеры, паузу и рабочие маршруты/кэши.
- Проверены 64 seed, продолжение одного боя до/после загрузки для трёх героев, некорректные ссылки и числа.
- Вкладка «Приказы»: группа, движение без отвлечения, движение с ответным боем, удержание H, отмена маршрута S, визуальные маршруты/места построения. Бойцы сохраняют разные конечные точки; закрытый проход означает ожидание с сохранённой целью.
- Отряд 21 человек проходит узкий коридор после закрытия, загрузки и открытия. Удар можно отменить без отложенного попадания. Отбрасывание не переносит сквозь стену.
- Перед сохранением сверяется сигнатура карты/строек: первый файл после сноса уже должен содержать согласованные открытые маршруты.
- Замер боевого полигона: 200/500 около 60 FPS, 1000 около 30 FPS на Ryzen 7800X3D/RX6650XT. Это временная графика, не слабый ПК. Полное сохранение 83 боевых записей: среднее 23.55 мс, p95 29.37 мс, 116692 байта; запись синхронная.
- Новый запрос автора: подготовить реальные вопросы о старте, своём клане, Империях, каноне, технологиях, торговле/ресурсах, чтобы отвечать с телефона. Созданы OWNER_QUESTIONS.md (30 вопросов, сначала 01–12) и GAMEPLAY_DIRECTION.md (рабочее предложение с явным статусом).
- Выборочно перечитаны паспорта Чёрного/Белого кланов, Империи Сумерек, экономика/огнестрел V4 из сентябрьского zip. Soft canon не объявлен подтверждённым. GitHub KROLIK-Collection-Vault по просмотренному корню содержит старое приложение Leemon, а не подтверждённую актуальную библию.
