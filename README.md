# GameKrolk

Прототип игры на Godot. Текущая версия 0.0.9 включает эпизод «Первый рубеж». Игрок снабжает поселение, выбирает, как его оборонять, и после боя может продолжить развитие.

## Запуск

На Windows откройте `START_GAME.cmd`, создайте новую партию и выберите «Начать „Первый рубеж“». Подробности в [FIRST_PLAY.md](FIRST_PLAY.md).

## Где смотреть код

- `scripts/` — игровая логика.
- `scenes/` — сцены Godot.
- `data/` — игровые данные.
- `tests/` — автоматические проверки.

Устройство проекта описано в [ARCHITECTURE.md](ARCHITECTURE.md). Что входит в текущую версию, указано в [STATUS_0.0.9.md](STATUS_0.0.9.md).
